# 理科ラボ 3（小学3年・理科）— 作り直し版（v3・未公開）

「学習アプリの標準の作り」に沿ってゼロベースで再構築した版です。公開はしていません（ローカルビルドのみ）。

## 構成
- トップ：ヘッダー（アプリ名＋小学3年・理科、音／ふりがな切替）、ナビキャラ6人の集合イラスト（全体表示）、研究ランク帯、単元カード10枚、とっくん／学習の記録／発見図鑑への入り口
- 単元ページ：担当キャラの全身＋ひとこと、大きなボタン「LABでためす」「もんだい」、3フェイズの進み具合
- もんだい：3フェイズ（①くらべて気づく 選択、②予想してためす 分類活動、③発見をまとめる 選択）。1問ごとに即時フィードバック＋解説
- とっくん：間違えた選択問題だけを集めて出題。正解で記録から消える（克服）。敵・HP・タイマーなし
- 学習の記録：単元ごとの進み具合、まちがい残件数、発見数、研究ランク・XP
- 発見図鑑：10単元×7件＝70件（フェイズ発見3＋大発見1＋LABミッション発見3）
- LAB：全10本のシミュレーション（条件変更→結果がアニメーションで変化、3回分の比較記録、安全注意・モデル注記あり、担当キャラのコメント欄つき）
- LABのあそびミッション：全10 LAB×3件。試行錯誤で達成する遊び（例：風とゴムLAB「車で120cmちょうどに進ませよう」）。達成判定はその場で表示し、達成すると発見図鑑に「LAB発見」として記録＋研究XP+10。門番にはしない（未達成でも進行は止まらない）。定義は labs/manifests.js の MISSIONS、判定は labs/third-labs.js の MISSION_CHECKS、記録は state.labMissions（保存キー不変・後方互換）
- LABの直接操作：全10 LABでステージ上の対象を直接さわれる（ドラッグ＝車・植物・太陽・光の的・磁石・音源・スイッチ・重さの物・生き物の背景スワイプ・昆虫のスワイプ、タップ＝従来分）

## LAB改良 第2弾（2026-11-08、画面側の演出）
ミッションではなく、実験ステージの「見た目と動き」を豊かにした。科学モデル・判定・読み出しの数値は不変で、変えたのは表示層だけ。
- 共通：ステージの「表示値」だけを requestAnimationFrame で補間する小さなアニメーター（createSceneAnimator）を導入し、状態が変わると場面が200〜600msで滑らかに追いつく。prefers-reduced-motion では即時表示。操作中の対象は drop-shadow で光るフィードバックを追加。場面には空・地面・机などの背景グラデーションと物の影を追加
- 風とゴム：車がタイヤ（スポーク付き）を回しながら実際に走る。風の流れの粒、ゴムは伸び具合で垂れ方が変わる形に
- 太陽：太陽が弧を滑らかに動き、影が伸び縮みする。空の色が時刻で変わり、地面の温度は温度計の水銀の上下で見える
- 植物：育ちが連続アニメーションに（茎が伸び、葉が1枚ずつ開き、花・実がふくらんで出る）
- 昆虫：段階が変わると前の姿が薄れて次の姿が出る。成虫チョウの羽ばたき、幼虫のうごめきを追加
- 音：音源の震え（強さ連動）、音の輪の広がり、糸を伝わるパルスの流れを追加。波の大きさも滑らかに変化
- 光：光の粒が線の上を流れる（入射・反射とも）。鏡の当たる点にきらめき
- 電気：点灯中は回路を光の粒が一周流れる（animateMotion）
- 磁石：クリップ6個と砂鉄が、鉄のときだけ距離に応じた強さで磁石の下へ集まる（アルミでは動かない）
- 重さ：上皿てんびんの場面に刷新。条件を変えると梁が傾いて揺れて釣り合い、物（左皿）とおもり（右皿・合計g表示）が乗る。粘土の形は丸↔平らが滑らかに変形。開いた直後は釣り合った状態で見せる
- 生き物：場所ごとの背景を描き分け（石の下＝大きな石と湿った土／花畑＝太陽・雲・花畑と草のゆれ／乾いた地面＝ひび割れと小石）。生き物に地面の影
- 合わせて削除した旧CSSアニメーション：carRoll・distanceGrow・shadowSettle・磁石の attract/repel（毎フレーム再描画と競合して残像化するため。本体の動きは表示値の補間に移行）

## 磁石LABの棒磁石化（2026-11-08、ユーザーの指摘対応）
磁石LABだけ、磁石の形と極の操作を直した。他の9 LAB・科学モデル・保存キー（rikaLab3.v3）は不変。
- 磁石を棒磁石の見た目に描き替え：横長の棒に赤（N極）・青（S極）の2色分け＋大きな N・S 文字。左右どちらの磁石も両極が見える
- 極の反転：棒磁石をタップすると ひっくり返って、相手に向く極が N⇔S に入れ替わる（右の磁石はドラッグと両立：ほぼ動かさず離したときだけ反転し、ずれた距離は戻す）。パネルの「左／右の棒磁石の極」ボタンでも切り替えでき、どちらも半回転の表示補間（scaleX）で滑らかに反転する。キーボードは Enter／Space で反転、右の磁石は矢印キーで距離
- 科学的な正しさは維持：鉄（クリップ・砂鉄）は N極でも S極でも引き付けられ、アルミはどちらの極でも付かない。距離に応じた吸着の演出も極を問わずそのまま。極どうしは同極＝しりぞけ合う・異極＝引き合う表示を維持
- ミッション3件（ちがう極どうし／力を100／距離3通り）は、向かい合う極の意味を変えていないため判定そのまま達成可能
