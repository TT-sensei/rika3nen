# 理科ラボ 3（小学3年・理科）— 作り直し版（v3・未公開）

「学習アプリの標準の作り」に沿ってゼロベースで再構築した版です。公開はしていません（ローカルビルドのみ）。

## 構成
- トップ：ヘッダー（アプリ名＋小学3年・理科、音／ふりがな切替）、ナビキャラ6人の集合イラスト（全体表示）、研究ランク帯、単元カード10枚、とっくん／学習の記録／発見図鑑への入り口
- 単元ページ：担当キャラの全身＋ひとこと、大きなボタン「LABでためす」「もんだい」、3フェイズの進み具合
- もんだい：3フェイズ（①くらべて気づく 選択、②予想してためす 分類活動、③発見をまとめる 選択）。1問ごとに即時フィードバック＋解説
- とっくん：間違えた選択問題だけを集めて出題。正解で記録から消える（克服）。敵・HP・タイマーなし
- 学習の記録：単元ごとの進み具合、まちがい残件数、発見数、研究ランク・XP
- 発見図鑑：10単元×4件＝40件（フェイズ発見3＋大発見1）
- LAB：全10本のシミュレーション（条件変更→結果がアニメーションで変化、3回分の比較記録、安全注意・モデル注記あり、担当キャラのコメント欄つき）

## 現行版から直した点
1. 選択肢シャッフル：現行版は全問で正解が choices の先頭（answer=0）固定だった。出題時にシャッフルし、正解位置を追跡する方式に変更
2. 研究ランクの「あとNaN XP」「0 / undefined XP」表示バグを解消（rankInfo は数値のみ返す実装に書き直し）
3. 問題画面でフェイズ切替タブが固定ヘッダー裏に隠れる崩れと、画面全体の黒枠のような表示を解消（画面遷移は1画面1ビュー方式に統一）

## データ・素材
- 問題データ（units.js：10単元、選択90問・分類30活動、全問解説つき）と LAB のモデル計算（labs/third-labs.js、labs/lab-core.js）は現行版からそのまま移植（内容の正確さ確認済み）。lab-core はパンくず文言とコメント通知フックのみ小さくパッチ
- LAB マニフェスト（labs/manifests.js）は現行 labs/index.js から分離。おまけ図鑑（asset-rewards.js）は今回スコープ外
- ナビキャラ画像は tt-sensei.github.io/navi-character- の共通基盤を参照（担当：生き物=さく、植物=なみ、昆虫=りく、風とゴム=そら、音=つき、太陽=そら、光=かい、電気=かい、磁石=りく、重さ=なみ）
- 音は sounds-recipe-、演出CSSは edu-effects（自前基盤のみ）。読み込めなくても本体は動作する
- 保存キー：`rikaLab3.v3`（旧データ移行なし）
- ふりがな：js/furigana.js、読み固定の言葉だけの辞書方式（最長一致＋MutationObserver）、既定ON・端末保存
