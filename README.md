# 理科ラボ 3

小学3年生理科を、条件を変えて現象を確かめるシミュレーションと、問題学習で学ぶブラウザ教材です。身近な自然や物の性質を「くらべて気づく」ことを大切にし、全10単元を収録しています。

## この教材の学び方

スタート画面は、次の2つの入口に分かれています。

- **シミュレーション**：条件を動かすと、図と結果がその場で変化します。条件を一つずつ変え、違いをくらべます。
- **問題を解く**：単元ごとに、知識・実験の準備・結果からの考察に取り組みます。

問題学習は、3年生の学びに合わせて次の流れで進みます。

1. くらべて気づく
2. 予想してためす
3. 発見をまとめる

LABは答えを当てるだけの問題集ではありません。スライダーや選択ボタンを操作し、変化した図と短い結果を見ながら、何度でも試せます。

## 収録単元とシミュレーション

| 単元 | LABで試すこと |
|---|---|
| 身近な生き物 | 明るさ・湿り方・植物の有無と、生き物の見つかりやすさをくらべる |
| 植物の育ち | 水・日光・経過日数と、植物の成長をくらべる |
| 昆虫の育ちと体 | チョウとバッタの育ち方、体のつくりの共通点と違いをくらべる |
| 風とゴムの力 | 力の大きさと、車が動く距離をくらべる |
| 音のせいしつ | ふるえの大きさと、音の伝わり方を見てみる |
| 太陽と地面 | 時刻、太陽の位置、影、地面の温度の変化をくらべる |
| 光のせいしつ | 鏡の向きや枚数と、反射した光の明るさをくらべる |
| 電気の通り道 | 回路のつながりと、材料による電気の通り方を確かめる |
| 磁石のせいしつ | 極の組み合わせ、距離、材料による磁石の働きをくらべる |
| 物と重さ | 形・材料・量を変えたときの重さをくらべる |

## 問題学習

- 単元ごとに、知識、実験・観察の準備、考察の問題を収録
- 答えを選ぶ問題と、条件を分類して実験方法を考える活動を用意
- 正解・不正解の結果と、単元ごとの進み具合を表示
- 全単元から出題する「まとめチェック」を搭載
- 学習記録は利用中のブラウザ内に保存

## 主な機能

- タブレットで操作しやすいレスポンシブUI
- LABごとのリセットと、条件を一つ進める操作
- 3年生のLABでは、実験結果を3回分まで画面上に並べて比較
- LABは入口を開いたときに読み込み、必要なファイルだけを使う遅延読み込み
- 研究ランク、発見図鑑、おまけコレクション
- 効果音のオン・オフ設定
- 学習記録はブラウザの localStorage に保存
- 外部API、APIキー、サーバー、データベース、外部フォントを使用しない構成
- GitHub Pagesでそのまま公開可能

## 安全に関する表示

太陽や光を扱うLABでは、太陽を直接見ない、人や道路へ光を向けない、燃えやすい物へ光を集めないことを示しています。電気や磁石、生き物の観察についても、実際の活動では先生の指示と安全な方法を優先してください。

- app.js：画面遷移、問題判定、進捗保存、LABの入口

- labs/index.js：LAB一覧と遅延読み込み
- labs/lab-core.js：LAB共通の画面・操作・結果表示
- labs/third-labs.js：3年生の単元別シミュレーション
- gamification.js / asset-rewards.js：研究ランク、発見、報酬表示
