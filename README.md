# 理科ラボ 3

小学3年生理科を、シミュレーションで動かして確かめ、問題で整理するブラウザ完結型の教材です。「くらべて気づく → 予想してためす → 発見をまとめる」の流れを、10単元でくり返します。

## 学び方

スタート画面は「シミュレーション」「問題を解く」の2タブです。

- シミュレーション：条件を変えると図と結果がその場で変化します。「この結果をくらべる」で、条件と結果を3回分並べられます。
- 問題を解く：既存の知識・実験準備・考察問題、進捗、まとめチェックを利用できます。
- 研究ランク、発見図鑑、おまけコレクションも従来どおり確認できます。

## シミュレーション

1. 生き物LAB：明るさ・湿り方とすみか
2. 植物LAB：水・日光・日数と成長
3. 昆虫LAB：チョウとバッタの育ち方・体のつくり
4. 風とゴムLAB：力の大きさと車の移動距離
5. 音LAB：ふるえの大きさと音
6. 太陽LAB：時刻・太陽の位置・影・地面の温度
7. 光LAB：鏡の向き・枚数と反射
8. 電気LAB：回路のつながり・6種類の材料と豆電球
9. 磁石LAB：極の組み合わせ・距離・材料
10. 重さLAB：形・材料・量と重さ

## 収録単元

1. 身近な生き物
2. 植物の育ち
3. 昆虫の育ちと体
4. 風とゴムの力
5. 音のせいしつ
6. 太陽と地面
7. 光のせいしつ
8. 電気の通り道
9. 磁石のせいしつ
10. 物と重さ

各単元に、同じところ・違うところを見つける知識4問、予想を確かめる観察・実験準備2活動、結果から発見をまとめる考察3問を収録しています。全10単元から1問ずつ出題する「まとめチェック」も利用できます。

## 特徴

- 3年生で中心となる「差異点や共通点を基に、問題を見いだす力」を重視
- 「くらべる → 気づく → 予想してためす → 発見をまとめる」を全単元で反復
- 「音のせいしつ」と「生き物と周りの環境」を含む学習指導要領対応の10単元
- タブレットで押しやすいレスポンシブUI
- 長文入力なしで、条件と結果を3回分並べて比較できる
- 生き物・成長・力・音・光・電気など、各現象に対応した短いアニメーション
- シミュレーション画面を触った場所が分かるタッチ反応（動きを減らす設定に対応）
- 実験・観察の条件、記録、安全をカードで分類
- 不正解時は誤ったカードだけを戻して学び直せる
- 既存の選択肢・正解・解説をそのまま使い、問題データを維持
- 進捗、初回正解、間違えたカードを `localStorage` に保存
- 既存の `rikaLab3.v1` の問題記録は `rikaLab3.v2` に自動移行
- 効果音はWeb Audio APIで端末内生成（初期設定はオフ）
- 外部API、APIキー、サーバー、データベース、外部フォント不使用
- GitHub Pagesでそのまま公開可能

## 安全への配慮

- 虫眼鏡や鏡で日光を扱う活動では、太陽を直接見ない、人や道路へ光を向けない、燃えやすい物へ集光しないことを明記
- 電気の活動は学校用乾電池だけを使い、家庭のコンセントへつながないことを明記
- 磁石を電子機器やカードへ近づけず、小さな磁石を口に入れないことを明記
- 生き物を必要以上に採集せず、観察後は元の場所へ戻すことを明記
